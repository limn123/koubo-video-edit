# 音效规范

## 原则

- **用真实录制的音效，不要程序合成**（合成的听着机械）。素材清单在 `assets/sfx_real/sfx_map.json`，用 `scripts/fetch_sfx.py` 下载、`scripts/mix_real.py` 混音。
- **每条按本条的动作重新搭配**，不照抄上一条的时间表。
- **默认不加背景音乐**，留给用户自己配。
- 用“爆款口播”那类一听就懂的声音：whoosh、pop、叮咚、综艺“嗡嗡”、收银机、快门。不要用奇怪的合成器声或拟音（用户原话：“音效有点怪怪的”）。
- **一类动作固定一种声音**，同类做变体轮换：whoosh 5 种、pop 6 个音高、推近“咚”2 种。
- **不密、不重复**（用户反馈“音效有一点重复”）：
  - 全片约 50 处（每分钟 30 左右），**任意 10 秒 ≤7 下**；同一个声音全片 ≤3 次。
  - 连续同类动作只在首、尾、最大处出声（比如 8 件衣服挂上衣架 → 3 下，三种声音；一排卡片点亮 → 1 声）。节奏一模一样的连响，换了音高也会被听成“重复”。
  - “嗖”（whoosh/swipe）只用在人物全屏↔圆环切换和换章节甩镜；同一章里换画面不“嗖”，用翻纸声或不出声。
  - 标签弹出不必每个都响；只给关键结论配印章、冲击。
- 模板里的 `cues.py` 会自动拦截：同一个声音连续出现、两个音效相距不到 0.25 秒、同一个声音超过 3 次、任意 10 秒超过 7 下。
- 音效卡在动作发生的那一帧上，通常是口播关键词起音前 0–0.15 秒。
- 电平：比人声峰值低，中位数 10–13 dB，最少 6 dB。冲击类（`hit`、`slam1/2`）最容易过响，全片不超过 3–4 下。
- 不默认加背景音乐。用户要的时候再加，并且人声出现时要压低。

## 动作 → 声音（真实音效，名字见 `assets/sfx_real/sfx_map.json`）

| 动作 | 音效名 | 是什么声音 |
| --- | --- | --- |
| 开场钩子、第一下重击 | `hit` | 快速推近的重击 |
| 人物全屏↔圆环、段落转场 | `whoosh` / `whoosh2` / `whoosh3` 轮换 | 三种“嗖” |
| 卡片、表格、纸条滑入 | `sheet` | 带风声的滑入 |
| 画面推近、吸进去 | `zoom_in` | 吸气式推近 |
| 标签、胶囊、名牌弹出 | `pop` / `tag_a` / `tag_b` / `tag_c` | 四种 pop |
| 贴在画面上的关键词逐个出现 | `float_a` / `float_b` / `float_c` | 泡泡、小咔哒、消息声 |
| 好、打勾、答对 | `ding1`、`tick_a`（清单每条）、`tick_b`（清单收尾） | 叮、click |
| 章节切换 | `ch1` / `ch2` / `ch3` | 三种提示铃，每章一种 |
| 关键结论大字（全片 ≤3 处） | `slam1` / `slam2` | 电影感重击 |
| 提醒、停一下、不对劲 | `stop` | boing |
| 纠结、晕、犹豫 | `dizzy` | 卡通眩晕 |
| 降价、变低 / 涨价、变高 | `down` / `up` | 下滑哨音 / 上跳 |
| 价格、钱、数字 | `stat_a`、`swing` | 金币、硬币 |
| 小字提示、免责说明 | `note` | 轻铃 |
| 结尾号召 | `ding3` | 成就铃 |

- 没有对应声音的动作（快门、印章、打字、关门……）：去 mixkit.co 按类别挑真实录制的，**把清单给用户确认后**再下载，存成 `mk_<编号>.mp3` 并在 `sfx_map.json` 里加一条，同时补进这张表。
- 音量已经写在 `sfx_map.json` 的 `gain` 里（相对人声峰值），`mix_real.py` 给口播再整体轻 2 dB，一般不用单独调。
- 每条片子按它自己的动作重新排，不要照搬上一条的时间表。
