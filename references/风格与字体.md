# 开工前定风格：字体、主色、节奏

用户反馈：“开干之前先看一下视频的风格，然后再去选择字体之类的。”
所以每条视频在写分镜、搭动效工程之前，先看片定调，**不再固定用一套字体**。背景纹样仍然固定用米白那套（硬规矩 3），这里只定纸面上的字体、主色、节奏和音效密度。

## 1. 先看什么（10 分钟内）

| 看什么 | 怎么看 | 影响什么 |
| --- | --- | --- |
| 场景 | 抽 4–8 帧（`contact.py --step 5`）：室内坐讲 / 户外走讲 / 样板间 / 车里 / 办公室 | 人物取景（圆环大小、全屏多还是圆环多），全屏标题放头顶还是侧边 |
| 构图 | 人在远景还是近景、脸在画面哪一块、头顶空多少 | `fullDY` 要不要下移；标题纸条放天空还是侧边空白列 |
| 光线 | 逆光 / 顺光 / 室内暗 | 逆光要给圆环补光（`face_gain.py`，只补圆环，全屏不动） |
| 话题调性 | 通读转写：吐槽避坑 / 干货数据 / 温情故事 / 高端楼盘 / 政策解读 | 字体组合、主色、动画节奏 |
| 说话状态 | 语速、情绪起伏、有没有手势 | 推近次数、音效密度 |
| 口播结构 | 开头有没有钩子、结尾有没有号召 | 要不要前置钩子、加结尾评论卡 |

## 2. 写一张“风格卡”放在 `分镜.md` 最前面

```
风格：户外边走边说 · 吐槽避坑 · 口语化
字体：标题 站酷快乐体 / 标注 站酷快乐体 / 数字 站酷快乐体 / 字幕 站酷快乐体（套 A）
主色：红（缺点）+ 绿（优点），橙做强调，蓝只用于“冷/低温”
节奏：中快；全屏推近每段 1–2 处；大字冲击 ≤2 处
音效：约 50 处，每 10 秒 ≤7 下
人物：远景小脸 → 圆环取头肩（半径跟脸宽走）；逆光 → 圆环补光
钩子：开头是铺垫，把“X 号楼屋里比别的楼冷两度”前置
结尾：没有号召 → 加结尾评论卡（标明是加的文字）
```

## 3. 字体组合（都在 `assets/fonts/` 和 `assets/fonts/fun/`，OFL 可商用）

| 套 | 标题 / 标注 | 字幕 | 适合 | 备注 |
| --- | --- | --- | --- | --- |
| A | 站酷快乐体 | 站酷快乐体 | 生活、吐槽、探盘、轻松口播 | 拿不准时的默认 |
| B | 得意黑（斜体） | 思源黑 Medium | 干货、数据、行情、价格对比 | 利落、信息感强 |
| C | 马善政毛笔 | 思源黑 Medium | 温情、养老、老小区、人情故事 | 毛笔只做标题 |
| D | 志莽行书 | 站酷快乐体 | 个人经历、感悟、“我当年……” | 行书只做标题 |
| E | 龙藏体 | 思源黑 Medium | 轻松 vlog、手写感 | 龙藏体笔画细，标题字号要 ≥96 |
| F | 思源黑 Medium | 思源黑 Medium | 高端楼盘、政策解读、严肃话题 | 最稳重 |

- **字幕只用好读的字体**（快乐体 / 得意黑 / 思源黑），毛笔、行书、龙藏体只用在标题和标注。
- 庆科黄油体不要用：“入”像“几”。
- 数字：A 用快乐体的数字；B/F 用得意黑或思源黑；C/D/E 的数字用快乐体或思源黑，**不要用毛笔、行书写数字**（不好认）。

## 4. 出样张、定下来

```bash
python $S/font_samples.py --video $W/rough.mp4 --t <有人物的一帧> \
  --title "<封面第一行>|<封面第二行>" --kicker "<小区名>" --sub "<口播里的一句>" --out $W/字体样张.jpg --sets A,B,C,F
```
- 样张用的就是这条视频的画面、这条的封面标题和一句字幕，按风格挑 3–4 套最可能的。
- **风格和这个账号以前认可过的一样**：直接用那一套，在回复里说一句“按上次的快乐体”，不用打断。
- **风格变了或拿不准**：把样张发给用户（SendUserFile），用 AskUserQuestion 让用户选，推荐的放第一个。
- 定下来后写进风格卡，并改：
  - `src/engine/fonts.ts`：登记字体文件；`SERIF` = 标题字体，`SANS` = 标注字体，`NUM` = 数字字体；思源黑放在后面作缺字回退（㎡、→ 等符号）。
  - `python $S/subset_fonts.py $M <标题字体完整路径> <标注字体> <思源黑>` 子集化。
  - 字幕：`make_subtitles.py --font <字幕字体路径> --fontname "<字体名>"`；`final_compose.py --fonts-dir <只放字幕字体的目录> --expect-font <字体名里的一个词>`。

## 5. 主色

米白纸面上的主色固定从这几个里挑，**一条片子只用 2 个主色 + 1 个强调色**：
- 橙 `#E07A35`（挂牌、价格、强调）、绿 `#2A8C5F`（好、优点、成交）、红 `#D9483B`（缺点、警示、下跌）、墨绿 `#183D33`（正文）
- 本条特有含义的色可以加一个，比如蓝 `#4E8DB5` 只用来表示“冷 / 温度低”。
