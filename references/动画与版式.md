# 动画与版式

所有坐标都是竖版设计坐标 1080×1920；渲染时 `--scale=2` 输出 2160×3840。

## 1. 版面分区

```
y 0–112      抖音顶栏：只放背景
y 112–185    留白
y 185–560    标题区：
             圆环段：左上 Title（kicker + 2 行标题，x 60–680）
             全屏段：米白纸条标题
             右上：人物圆环，中心 (880, 360)，r=150，禁放区 x 700–1080、y 170–540
y 560–1310   主视觉区：讲解卡片、照片、图形，x 60–970（版心裁切角标 572 / 1300）
y 1310–1400  字幕带：圆环段字幕底边 y≈1390（ASS 2780）；全屏段字幕在锁骨位置，底边 y≈1470（ASS 2940）
y 1430–1494  章节进度条，在 bg.tsx 里
y ≥1500      透视地面、镂空章节大字等装饰；作者名、文案从 y≈1607 开始，不放内容
右侧按钮图标 圆心 x≈1010、半径≈48，y 875–1720：卡片边压一点没关系，图标本身不要盖住文字或关键图形
```

- **按宽松安全区排**（用户：底部还留很多，右边压一点点没关系）：主信息在 x 33–975、y 112–1600 以内。卡片右边缘到 x≈970 可以；文字、数字不要伸到按钮图标底下。
- 印章、斜放的标签、旋转的卡片按旋转后的外框算。
- 底部放宽后主视觉区比以前高约 130 像素（560–1310），卡片和元素可以做得更大，别留着大片空白。
- 字幕带和进度条已经下移（字幕底边 1390、进度条 1430–1494），主视觉区一直用到 y 1310。
- 字号下限：
  - 胶囊标签 32（`Pill` 已强制）
  - 说明文字 ≥ 28
  - 标题 ≥ 56
  - 数字大号 ≥ 48
- “示意”“口播数据”这类注脚可以用 24。

## 2. 人物：全屏 / 圆环

- `project.ts` 的 `MODES` 控制人物状态，过渡约 0.5–0.62 秒。
  - 讲解段：人物缩进右上圆环。
  - 没有讲解作用的句子全屏，比如开场钩子、“看三样”这类总起、“一个毛病”这类总结、入行背书、结尾号召。
- 剪点（删掉的卡顿）尽量落在圆环段里，这样看不到跳切。
- **全屏下移 `FULL_DY_SEG`**：发际线 ≈ 人脸跟踪 y − 350，取值让发际线 ≥ 610，通常是 80–125。切换值都放在圆环段里。
- **全屏推近 `hook.tsx` 的 `PUNCH`**：说到关键词时快速推近 3.5–6%，保持 0.5–2 秒后缓回，每段全屏 1–3 处。
  - 开场 0–0.55 秒有一个从 1.06 拉回 1 的开机推拉。
  - 推近后发际线仍要在标题纸条下面。
- 全屏标题是 `FULL_TITLES`：米白纸条 + 墨绿字，关键词垫彩色斜切色块，逐行出现的时间卡口播。头顶空出来的那一条就是米白纸面本身，不加暗色渐变。

## 3. 开头钩子（0–6 秒，人物全屏）

- 第 0 帧就是完整封面：kicker 胶带 +“问题”两行纸条，字号约 84，给右边留出一列。
- 从第 0 帧起画面就在动：开机拉镜，加一个已经在场、正在晃的道具。
- 跟着口播关键词卡 2–4 个动作：道具被砍/被拽/被点亮、关键词变红跳动、刀光或扫光划过纸条、人物推近。每个动作配音效，其中一个是冲击音效（剁、砸 + 低音）。
- 道具只放在纸条右侧那一列（x ≈ 900–1060，y 200–480）或头顶，不压脸。
- 开头用过的比喻，后面讲解段不再用。

## 4. 转场：每段换一种

`parts2.tsx` 的 `Block` 支持这些进场和出场：

- 进场：`iris`（圆形展开，从圆环中心 880,360）、`slideL/slideR`（横推）、`up`（上推）、`zoom`（放大）、`wipe`（斜擦）、`drop`（落下）、`fade`
- 出场：`zoomOut`、`shrink`、`slideL/slideR`、`iris`（收拢）、`fall`、`up`、`wipe`、`drop`、`fade`
- 章节切换用甩镜：在 `bg.tsx` 的 `WHIPS` 加时间点，`Block` 用 `slideL`。

其他要求：
- 相邻两段的进场方式不同。
- 段内加 `cam` 推镜，2–4 个关键帧。
- **推镜只在纸面里放大**：要放大很多（比如点阵推进去找某一个点）时，用一个 `overflow:hidden` 的版心容器包住内容再放大，别用 `Block cam` 放大整层，否则会盖住标题和圆环。
- 连续几问（“先问三句”）可以做成一条横向长舞台，镜头先拉远再横移到下一站（见 S6_Ask）。

## 5. 比喻动画

每一句要解释的话配一个具体的比喻动作，全片不重复。下面是已经用过的，新视频优先想新的，用过的可以换个形式。

- **示例工程**：
  - 菜刀剁价签、心跳、刀光
  - 断开的价格条 + 放大镜
  - 月历翻页、买家消息、长短条落差
  - 接/不接按钮 + 光标、翻牌、夜里抛硬币
  - 扇形底牌、更便宜的房子落桌
  - 走势线、实拍照片落在航拍上、价签环绕
  - VS 卡、仪表盘、排队格子
  - 库存照片堆、漏斗、100 人点阵推镜
  - 出价单 + 印章、价签数字滚动、推门离开
  - 侧脸剪影 + 锚点、价签顶开、12 格月历
  - 锁链崩断、法槌、瀑布柱、罗盘
  - 心电线 + 没插上的插头、硬币飞进礼盒、蛛网 + 撕日历
  - 手机打字又删掉、卷尺、雷达、沙漏时间轴、天平、结尾评论框示范
- **另一条示例**：
  - 带看日历、已读不回的消息、“已售”横幅、跷跷板
  - 成交小票打印、合同被划掉、柱子塌下、账本翻开
  - 价签被顶高、放大镜对比、买家走掉
  - 平面图车流、复制粘贴价格、窗帘拉开看见马路、价格台阶
  - 沙漏、一刀降到“不等线”、手里三张牌、首付硬币锁进房子
  - 签约彩带、三站路线、文件夹抽出自查表

强调方式也要换着用：
- 大字冲击 `Kinetic slam`：全片 ≤3 处，留给最关键的结论，例如“降了四成多”“整整 50 万”。
- 其他用荧光笔、划掉、手绘圈 `MarkCircle`、印章 `Stamp`、胶囊弹出、数字滚动。

## 6. 数据与照片

- 画面里的数字、名称、年份必须来自口播或文案，并且和口播一致。
- 走势形状、举例、示例留言要标“示意”或“示例”。
- 示例数字要和片中的数据量级一致：比如前面说二手五六千一平，示例挂价就不能写 85 万。
- 素材照片：说到某个小区就用 `Snap` 快门照片落下，配 `shutter` 音效。照片说明写小区名，有出入就标“示意”。
