# 音效规范

## 原则

- **每条视频重新合成。** 复制上一条的 `sfx_vN.py`，换随机种子、调频率和包络，补上本条新动作的声音。不要直接拷上一条的 `public/sfx`。
- 用“爆款口播”那类一听就懂的声音：whoosh、pop、叮咚、综艺“嗡嗡”、收银机、快门。不要用奇怪的合成器声或拟音（用户原话：“音效有点怪怪的”）。
- **一类动作固定一种声音**，同类做变体轮换：whoosh 5 种、pop 6 个音高、推近“咚”2 种。
- `cues.py` 会自动拦截：
  - 同一个声音连续出现（`ALLOW_REPEAT` 里的连续动作除外，比如快门连拍、硬币一枚枚飞、撕日历、打字）；
  - 两个音效相距不到 0.25 秒（较晚的那个会被合并跳过，要挪开）；
  - 同一个声音全片超过 12 次。
- 音效卡在动作发生的那一帧上，通常是口播关键词起音前 0–0.15 秒。
- 电平：比人声峰值低，中位数 10–13 dB，最少 6 dB。用 `sfx_headroom.py` 检查。冲击类最容易过响，开场剁刀 0.16、boom 0.07 是合适的量级。
- 不默认加背景音乐。用户要的时候再加，并且人声出现时要压低。

## 动作 → 声音

| 动作 | 声音 | 建议音量（cues 里的值，× GAIN 1.7） |
| --- | --- | --- |
| 人物缩放、段落转场 | whoosh_1..5 轮换 | 0.12–0.16 |
| 章节切换（甩镜） | swipe（快扫 + 小低音） | 0.17 |
| 下坠、变灰、收拢 | whoosh_down | 0.07–0.1 |
| 实景照片 | shutter 快门 | 0.08–0.12 |
| 标签、卡片、胶囊弹出 | pop_1..6 | 0.08–0.1 |
| 好、打勾 / 不好、打叉 / 疑问 | correct 叮咚 / wrong 嗡嗡 / question 上扬“嗯？” | 0.07–0.09 |
| 消息 | notify | 0.08–0.1 |
| 价格、钱 | cash 收银机、coin_fly 硬币飞 | 0.08–0.1 |
| 降价 / 暴跌 | slide_down / drop_duang（长下滑 + 落地） | 0.08–0.13 |
| 数字滚动、长条生长 | tick | 0.07 |
| 结论大字 | slam + boom，全片 ≤3 处 | 0.15 + 0.1 |
| 全屏关键词推近 | punch_1/2（轻“咚”） | 0.08–0.1 |
| 印章 / 荧光笔、划掉 | stamp / marker | 0.12–0.15 / 0.07–0.1 |
| 菜刀剁 / 刀光 | chop / blade | 0.16 / 0.08–0.13 |
| 心慌 | heartbeat | 0.12 |
| 抛硬币 / 晃动、回弹 | coin_toss / boing | 0.06–0.12 |
| 法槌 / 锁链断 / 关门 | gavel / chain / door | 0.13–0.16 |
| 雷达 / 打字 / 删字 / 卷尺 | radar / typing、typing_s / backspace / tape | 0.09–0.11 |
| 礼盒 / 撕日历 / 照片砸进堆 / 漏斗滴落 | gift / tear / thud_stack / drip | 0.09–0.12 |
| 翻月历 / 钟表 / 罗盘 / 天平 / 夜晚 | flip / clock / spin / balance / night | 0.08–0.1 |
| 脚步离开 | steps_away | 0.08–0.1 |
| 结尾 | chime_end 上行和弦 | 0.1 |

新动作没有对应的声音时，就在 `sfx_vN.py` 里加一个，同时把这张表补全，写进剪辑说明。
