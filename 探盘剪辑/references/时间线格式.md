# 时间线格式和现有积木

`scripts/build_main.py` 用 `tl_lib.Timeline` 生成 `src/data/main.json`；`src/Vlog.tsx` 照它出画面，`scripts/audio_mix.py` 照它出声音。画布是 1080×1920 设计坐标，时间单位都是成片里的秒。

这些积木是"现在有的"，不是"必须用的"。先想这条片子需要什么，再来这里找；没有合适的就在 `Vlog.tsx` 里新写一个组件，并在 `Inserts` 或 `Overlays` 的分发里加一行。

## 顶层
| 字段 | 说明 |
|---|---|
| `fps` / `clipdir` | 30 + `clips`（预览）或 60 + `clips4k`（出 4K60），由环境变量 `VLOG_FPS`、`VLOG_CLIPDIR` 控制 |
| `colors` | `{a, b, c, hl, ink}`：a/b 是这条的两个主色（比如两个对比对象），c 第三色，hl 重点色，ink 描边。组件里的 `color` 可以写这些名字，也可以直接写色值 |
| `fonts` | `{title: {family, file}, body: {family, file}}`，文件在 `public/fonts/`。不写就是得意黑 + 思源黑 |
| `sub_y` | 字幕底边，默认 1470；近景大脸往下放，最多 1600 |

## 主线 `base`（`tl.play` / `tl.hold` 生成）
`{src, t0, t1, from, rate, freeze?}`：从代理 `src` 的第 `from` 秒开始、按 `rate` 倍速播。全屏铺满，原色。

## 实拍插入 `ins`（`tl.insert(kind, t0, t1, …)`）——盖住主线画面，声音不断
| kind | 参数 | 用途 |
|---|---|---|
| `video` | `src, from, rate?, punch?` | 一段实拍。`punch: 1` 入画时有个 8% 的回弹，适合卡点快切 |
| `img` | `src, zoom: [起, 止], pos: "x% y%", tag?: {text, arrow?: up/down, color}, ring?` | 照片推拉（沙盘、大门）。`tag` 在中间贴一个大标签；`ring` 画圈圈出中间的东西 |
| `split` | `split_at, a: {src, pos, name, sub, color}, b: {…}, notags?` | 先 a 满屏，到 `split_at` 变成上下分屏对比，各带名牌 |
| `flash` | `every, srcs: [{src, pos}]` | 几张图来回快闪（纠结、对比不过来） |
| `table` | `title, cols: [{name, color}], rows: [比较项…], foot?, bg?` | 资料卡预览：只露表头和比较项，格子里的内容是虚化的（引导领资料时用，不泄露具体数字） |

## 叠加包装 `ov`（`tl.overlay(kind, t0, t1, …)`）
| kind | 参数 | 位置 / 用途 |
|---|---|---|
| `cover` | `small?, big, hl?, size?` | 顶部大标题（第 0 帧就在）。`hl` 是 `big` 里标成重点色的词 |
| `chip` | `text, y` | 一句话标签，居中，重点色底。y 一般 210（脸上方） |
| `name` | `name, sub, color, top?` | 左侧名牌（楼盘名 + 一句说明） |
| `same` | `items: [[t, 文字]…]` | 左上打勾清单，逐条弹出 |
| `compare` | `rows: [[t, 名, 文字, color]…]` | 左上两行对照（A 怎样 / B 怎样） |
| `stats` | `items: [[t, 名, 数值]…], color` | 左侧参数卡，数字放大 |
| `floats` | `items: [[t, 文字, x, y]…]` | 贴在实拍上的几个关键词，逐个弹出 |
| `chapter` | `n, text, color` | 章节号：先在中间亮一下，再缩到左上角常驻到 t1 |
| `three` | `items: [三个短语]` | 画面中下方一排 ①②③ |
| `slam` | `lines: [两行], hl: 第几行标色` | 大字冲击，全片 ≤3 处，放上半屏 |
| `title` | `small, big, color` | 一段实拍的片头大字（户型、区域） |
| `badge` | `text, label?, color?` | 左上常驻牌："实拍｜XX 户型" |
| `note` | `text` | 左上小字（免责说明） |
| `room` | `text` | 房间/地点标签，带定位图标 |
| `bridge` | `text` | 换场时左上一行小字 |
| `stop` | `text?` | 左侧八角牌（默认"停"） |
| `pricetag` | `text` | 晃一下的吊牌 |
| `comment` | `text`（口令） | "评论区打「…」" + 箭头指评论按钮 |
| `dm` | `text` | 顶部私信引导条 |
| `push` | `scale` | 底层画面缓慢推近（强调一句话） |
| `zoomcut` | `scale` | 底层画面直接放大到 t1（盖剪点的跳切） |

## 字幕 `subs`
`{t0, t1, text, hl: [关键词…]}`。`tl.play(lines=…)` 和 `tl.sub()` 会自动把超过 11 个字的句子拆成两段（逗号处，或者你用 `|` 指定断点）。断句别拆开数字和单位、动词和宾语。

## 声音
- `voice`：`tl.play(source=…)` 自动生成；`tl.ambient()` 加现场声。
- `sfx`：`tl.cue(t, name)`，`name` 见 `public/sfx_real/sfx_map.json`（每个都写了用途）。要新声音：从 mixkit.co 挑（预览地址 `https://assets.mixkit.co/active_storage/sfx/<编号>/<编号>-preview.mp3`），**先把清单给用户确认再下载**，存成 `mk_<编号>.mp3` 并在 sfx_map.json 里加一条。`align: "peak"` 用于嗖和重击（最响那一下对准动作帧），其它用 `"on"`。

## 新写组件时注意
- 取当前帧用 `useFrame30()`，时间换帧用 `f30()`，弹簧用 `pop(frame, 30, 延迟)`——这样动画在 30 帧和 60 帧下一样快。`useFrame30` 内部必须读 `useVideoConfig().fps`，别改。
- 位置：脸通常在画面中间偏上，标签放顶部（y 110–330）或胸口以下（y 1100–1350）；右侧 x>975 留给抖音按钮。
- 做完抽帧看一眼，别凭感觉。
